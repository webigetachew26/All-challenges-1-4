
Diary Manager

Diary Manager is a Java-based diary application with both JavaFX GUI and console-based versions.
It allows users to write, save, load, search, and back up personal diary entries.

Features

Write and save diary entries

Load diary content from file

Search diary entries by keyword

Backup entries as ZIP file

JavaFX UI with CSS styling

Background file loading using Task


Technologies

Java

JavaFX

File I/O

CSS


How to Run

GUI Version: Run DiaryManager (JavaFX)

Console Version: Run DiaryManager (CLI)
